Cursor · Claude Code · Windsurf · Antigravity

在开发者让 AI 写下第一行代码前，自动调用沙盘商业模型进行事前验尸。一旦发现致命短板（零需求、负毛利、上游绞杀），智能体主动在控制台亮红灯拦截代码生成，并输出 3 条最小化闭环验证避坑指南。

推荐 方式一：终端一键自动安装 (Auto-Installer)

直接在终端运行以下命令，会自动识别本机安装的 Cursor / Windsurf / Claude 并无缝注入配置与熔断规则：

npx -y deadlab --install
方式二：各 IDE 手动快速配置指南
⚡ Cursor

打开 ~/.cursor/mcp.json (或项目根目录 .cursor/mcp.json) 添加：

{
  "mcpServers": {
    "deadlab": {
      "command": "npx",
      "args": ["-y", "deadlab", "--mcp"]
    }
  }
}
🧠 Claude Code (Anthropic CLI)

在终端中直接执行一行命令完成关联：

claude mcp add deadlab npx -y deadlab --mcp

或在 Claude Desktop 的 claude_desktop_config.json 中挂载相同配置。

🌊 Windsurf (Codeium Cascade)

打开 ~/.codeium/windsurf/mcp_config.json 添加：

{
  "mcpServers": {
    "deadlab": {
      "command": "npx",
      "args": ["-y", "deadlab", "--mcp"]
    }
  }
}
🛡️ 配合 IDE 规则生效 (.cursorrules / CLAUDE.md / .windsurfrules):

在项目根目录新建规则文件，告知 AI 助手在写业务功能前必须主动向 DEADLAB 请示商业许可：

# DEADLAB 商业立项熔断规范
Before scaffolding files or writing code for new features or business ideas:
1. Call the `deadlab_check` or `deadlab_circuit_breaker` MCP tool.
2. If `isFatal: true` or circuit breaker triggers, STOP code generation immediately and challenge the user on demand validation and unit margins.
CLI TOOL

终端极客命令行 (npx deadlab-check)

无需配置复杂的 GUI 环境，直接在 Terminal 控制台完成项目沙盘推演，支持彩色 ASCII 卦象绘制与 JSON 输出： 

# 1. 运行典型预设案例 (ai-wrapper / solo-saas / open-source / hard-tech)
npx deadlab-check --preset ai-wrapper

# 2. 自定义项目六爻推演
npx deadlab-check --need 2 --cap 2 --econ 0 --dist 3 --dep 1 --stam 2

# 3. 输出纯 JSON (供 CI/CD 自动化或脚本集成)
npx deadlab-check --preset solo-saas --json

RETURNS

字段说明
s12
24 个月存活率（0–1）
s
长度 25 的生存曲线，s[t] = 第 t 个月仍活着的比例
median
中位死亡月（0–24，24 表示活过两年）
causeShare
死因占比 { demo, trust, cost, dist, dep, burn }
outTop
活下来的最可能形态 [名称, 次数]
vetoed
是否被一票否决；为 true 时 s12 = 0
